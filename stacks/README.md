# Stacks

Versioned library of reusable technical stack definitions.

Detailed manifests and implementations are not created by this skeleton step.

Stack resolution must activate only components required by the selected
workload.

## Core Platform stack

Qualified stack definition:

```text
stacks/core-platform/stack.env
```

Documentation:

```text
stacks/core-platform/README.md
```

The current B17b-E implementation qualifies stack definition, resolution and prerequisite evaluation only.

It does not install prerequisites or manage runtime instances.
